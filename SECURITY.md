# Security Policy

## Supported versions

Studydeck is still under active development. Security fixes are applied to the latest release and
the current `main` branch. Older releases are not maintained separately.

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/AUser3/study-deck/security/advisories/new).
Do not open a public issue for a vulnerability.

Include enough information to reproduce and assess the problem when possible:

- the affected version or commit;
- the operating system and runtime environment;
- steps to reproduce the issue;
- the expected and observed behavior;
- the potential impact; and
- any suggested mitigation or fix.

Do not include personal study data, credentials, access tokens, or other secrets in the report.
Please allow the maintainer reasonable time to investigate and prepare a fix before publicly
disclosing the issue.
